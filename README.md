# generator-hesiel

Secure password generator with a strength meter.

## Run

Requires Python 3.

```bash
python generator_hesiel.py
python generator_hesiel_gui.py
```

## Notes

- Choose lowercase, uppercase, digits and special characters
- Strength shown in bits of entropy (length × log₂ alphabet size)
